## 📂 Featured System Engineering Projects

### 🚗 1. Safety-Critical Automotive ECU Firmware & Diagnostics
* **Specialization:** Automotive Mobility, Safety-Critical Systems, Energy Storage & BMS
* **Architecture:** NXP S32K118 microcontrollers in C for production validation.
* **Key Accomplishments:**
  * Implemented core platform startup code, interrupt vector management, and Memory Protection Unit (MPU) configuration.
  * Developed SCST (Self-Test) functional safety mechanisms for boot and runtime execution.
  * Designed UDS Diagnostic Services (ISO 14229) including DID handling, Security Access algorithms, and DTC fault memory logging.

### 🤖 2. Autonomous Systems Control & Sensor Fusion Benches
* **Specialization:** Advanced Robotics, Autonomous Vehicles, Intelligent Edge
* **Architecture:** MATLAB/Simulink, Embedded C/C++, ROS 2, IMU + GNSS integration.
* **Key Accomplishments:**
  * Implemented real-time PID closed-loop control systems for dynamic physical stabilization.
  * Integrated IMU motion processing (ICM-20607 / MPU6050) and GNSS NMEA sentence parsing over UART/SPI.
  * Developed Python/Qt-based automated HIL test benches on Raspberry Pi Linux for sensor telemetry injection.

### 📡 3. Multi-Radio Connected Industrial Telematics & Low-Power Edge
* **Specialization:** Industrial IoT Edge, Connected Systems, Smart Energy
* **Architecture:** Nordic nRF52840 (BLE), ESP32 (Wi-Fi), PIC32MZ, Cellular 3G/4G.
* **Key Accomplishments:**
  * Designed low-power state machines and BLE GATT services (nRF5 SDK / FreeRTOS), reducing standby current draw for battery-powered edge devices.
  * Built TCP/IP, MQTT, and WebSocket pipelines for over-the-air (OTA) firmware updates and cloud telemetry synchronization.
  * Integrated peripheral buses (I2C, SPI, UART, I2S) for DEX data extraction and commercial audio processing.
